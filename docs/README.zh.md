# 网络控制 4.1

[English](../README.md) · [Español](../LEEME.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Português](README.pt.md) · [Русский](README.ru.md)

适用于 Windows 的本地网络面板，可发现设备、根据 MAC 地址识别制造商，并管理设备的访问权限。

## 开始使用

1. 安装 [Npcap](https://npcap.com/#download)。
2. 使用旧版本中的**退出**按钮关闭程序。
3. 运行 **ControlRed-v4.1.exe**，必要时以管理员身份运行。
4. 选择物理以太网或 Wi-Fi 适配器。
5. 在面板顶部的语言栏中选择**简体中文**。

语言偏好保存在浏览器中。更改语言不会修改设备的自定义名称或访问权限。运行 Demostracion.cmd 可打开模拟演示环境。

## 管理访问权限

在**手动阻止**模式下，可单独选择要阻止的设备。在**允许列表**模式下，发现未经授权的设备时，程序会请求阻止。点击**允许**或**添加允许的 MAC**可授权设备。路由器和此电脑始终受到保护。

请保持电脑和程序运行；可以关闭浏览器标签页。阻止操作将持续到您手动取消或退出程序。IPv6 需要发现地址及路由器。网络保护机制可能限制阻止效果。

启动时扫描一次，之后请点击刷新网络。无需定期扫描即可持续控制。通过观察本地流量可能发现新设备；如缺少设备，请刷新网络。

阻止效果取决于网络和设备的防护功能。“已请求阻止”不代表已经验证设备无法上网。请仅在您拥有或有权管理的网络中使用本程序。
