# Управление сетью 4.1

[English](../README.md) · [Español](../LEEME.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [简体中文](README.zh.md) · [Português](README.pt.md)

Локальная панель для Windows позволяет находить устройства, определять производителя по MAC-адресу и управлять доступом к сети.

## Запуск

1. Установите [Npcap](https://npcap.com/#download).
2. Закройте предыдущую версию кнопкой **Выйти**.
3. Запустите **ControlRed-v4.1.exe**, при необходимости от имени администратора.
4. Выберите физический адаптер Ethernet или Wi-Fi.
5. Нажмите **Русский** в строке выбора языка в верхней части панели.

Выбранный язык сохраняется в браузере. Имена устройств и разрешения не меняются. Файл Demostracion.cmd открывает демонстрационную среду.

## Управление доступом

В режиме **Ручная блокировка** устройства выбираются отдельно. В режиме **Белый список** для каждого обнаруженного устройства без разрешения запрашивается блокировка. Нажмите **Разрешить** или **Добавить разрешённый MAC**, чтобы предоставить доступ. Маршрутизатор и этот ПК защищены.

Оставляйте ПК и программу включёнными; вкладку можно закрыть. Блокировки действуют до их отключения или выхода из программы. Для IPv6 нужно обнаружить адреса и маршрутизатор. Защитные механизмы сети могут ограничивать блокировку.

Один поиск при запуске; затем используйте Обновить сеть. Контроль продолжается без периодического сканирования. Новые устройства могут обнаруживаться по локальному трафику; обновите сеть, если устройство отсутствует.

Эффективность зависит от сети и защиты устройств. Запрос блокировки не подтверждает отсутствие доступа в интернет. Используйте программу только в сетях, которыми вы имеете право управлять.

Сведения об исходном коде, тестах и сборке доступны в [README на английском](../README.md).
